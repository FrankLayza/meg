# Contributor 3: Presentation Surface & Demo Experience

This package owns the independently runnable user-facing presentation surface for **Milestone-Escrow Guardian**. It provides both a rich ANSI Terminal UI (designed for terminal-based video recordings and fast testing) and an interactive local Web Dashboard (`http://localhost:3000`).

It remains **independently runnable** using bundled fixtures, requiring neither live Python environments nor live blockchain RPC connections. When live pipeline outputs from Contributor 1 (`decision.schema.json`) and Contributor 2 (`policy-result.schema.json`) are available, it renders the unified audit trail.

---

## Architecture: The 5 Visual Stages

Both the Terminal UI and Web Dashboard clearly separate:

1. **Recalled Sibyl Context:** Project criteria, evolving stakeholder feedback, and unresolved issues with explicit tier mapping (`HOT`, `WARM`, `REFERENCE`, `COLD`).
2. **Submitted Deliverable:** Ingested commit summaries, locator URLs, and content hashes (treated strictly as untrusted data).
3. **Guardian AI Verdict [Advisory]:** Recommendation (`approve`, `request_revision`, `escalate`), confidence score, rationale, cited memory IDs, and identified gaps. *(Safety invariant: Model cannot move money).*
4. **Deterministic Policy Gate [Enforced]:** Itemized safety checks (escrow funded, dispute-free, under release cap, allowlisted contract, user confirmation).
5. **Base Sepolia Escrow Execution:** Release action, locked ETH amount, transaction hash, Basescan explorer link, and receipt confirmation.

## Quickstart

### 1. Terminal UI Walkthrough

Run the interactive scenario selector:
```powershell
pnpm run demo
```

Or run a specific scenario directly:
```powershell
# Scenario 1: Fresh-session recall detects missing idempotency -> revision required
pnpm run demo:revision

# Scenario 2: Revised commit satisfies criteria -> policy passes -> Base Sepolia release
pnpm run demo:approved

# Scenario 3: Open dispute or deleted memory -> fails closed to escalation
pnpm run demo:escalated

# Run full 3-part storyboard with interactive pauses
pnpm run demo:walkthrough

# Reset demo caches
pnpm run demo:reset
```

### 2. Standalone Web Dashboard

Start the built-in zero-dependency HTTP server:
```powershell
pnpm run serve
```
Open [http://localhost:3000](http://localhost:3000) in your browser to interact with the responsive web dashboard.

### 3. Live Composite Mode

Render output generated by a live pipeline run:
```powershell
pnpm run demo -- --fixture ../../shared/fixtures/review-request-approved.json --decision ../contributor-1-guardian/decision.json --policy ../contributor-2-escrow/policy-result.json
```
